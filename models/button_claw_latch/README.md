# 默认常开按钮锁爪机构

本目录是对旧直推插销方案的修订，不再只有“按钮加弹簧”。结构是 **蓝色按钮推杆 → 绿色连杆 → 橙色旋转锁爪 → 金色门板扣销**，包括主轴、两颗连接铆钉、弹簧承压垫圈、上盖与四套 M3 穿透螺栓/螺母。

动作目标是 **按住锁闭，松开弹簧复位打开**，不是按一下自锁。当前模型验证几何与离散运动位置，没有验证实际弹力、摩擦与载荷，不能当作已完成生产认证的锁具。

## 打开与观察

| 文件 | 状态 |
| --- | --- |
| `claw_latch_open.gasm` | 默认常开：锁爪 40°，按钮位于释放端 |
| `claw_latch_closed.gasm` | 按钮推入 6.3136 mm：锁爪转至 0°，挡住扣销 |
| `claw_latch_angle_10.gasm`、`angle_20.gasm`、`angle_30.gasm` | 三个中间位置，各有相应压簧几何 |
| `claw_latch_released.gasm` | 常开后门板沿 +X 退出 18 mm |
| `claw_latch_exploded.gasm` | 上盖及其紧固件分离，查看装配关系 |

`.gasm` 引用同目录的 16 种 `.gform` 文件，共装配 20 个组件；不要单独移动文件。开闭配置是按机构方程计算的静态位置，不是带接触、弹力求解的实时动力学仿真。

内部截图为方便观察隐藏上盖和其紧固件，**检查与 STEP 导出仍包含全部组件**。截图文件为 `claw_latch_open.png`、`claw_latch_closed.png`、`claw_latch_middle.png`。

## 关键尺寸

| 项目 | 设计值 / 单位 mm |
| --- | --- |
| 底板 | 148 × 62 × 4；底板上最高支柱至 Z=18 |
| 上盖 | 80 × 54 × 2；Z=18～20 |
| 锁爪 / 连杆厚度 | 4 / 3 |
| 主转轴 | Ø4，长 15；锁爪主孔 Ø4.4 |
| 连杆中心距 / 曲柄半径 | 24 / 10 |
| 扣销 | Ø6，锁爪圆袋 Ø6.8 |
| 按钮直径 / 推杆截面 | Ø12 / 6 × 4 |
| 铆钉轴径 / 连接孔径 | Ø3 / Ø3.4 |
| 上盖螺栓 | 4 × M3×25，配六角螺母；螺纹为包络简化 |
| 弹簧包络 | 线径 1、平均直径 9.4、四圈；端部承压环外径 10.5、内径 8.3 |
| 两垫圈承压面间距 | 常开 11.8136，闭合 5.5 |

尺寸是本次演示设计值，不是来自已选定供应商的规格。弹簧端环用于表达闭口、承压与定位关系；不同状态通过改变螺距表达压缩，未保持严格等体积弹性变形，也不是生产级弹簧绕制路径。

## 本次修正

- 框架支柱、主轴座和导向块以实际体积连接到基板，修正原来仅面接触的特征。
- 按钮与推杆、扣销与门板、铆钉两端头均补足连接；整体外部尺寸保持。
- 框架两个让位口改为圆端槽，刀具半径不小于 1 mm，消除这两处尖内角加工警告。
- 弹簧两端补承压环，与垫圈在五种状态均接触；并保留弹簧外购报价待定提示。
- 通过 MCP 修改与保存零件，不直接写 BRep 几何。修复脚本根据特征名称定位，并检查工艺元数据未丢失。

## 检查与剩余事项

- `part_check_*.json`：16 种零件的原生设计检查。修正后零件均无错误；未选材料的警告保留。`*_before.json` 是历史报告，不是当前结论。
- `design_check_open.json`、`design_check_middle.json`、`design_check_closed.json`：完整未过滤装配设计检查。常开和中间位置为 0 错误、6 警告；闭合为 0 错误、7 警告。
- 装配警告：四处螺栓径向间隙 0.20、主轴径向间隙 0.20，低于通用规则 0.5；闭合另有扣销间隙 0.40；弹簧无供应商报价。未放宽规则或删除这些警告。配合公差仍须正式确定。
- `verification.json`：16 个单实体有效性；5 个装配各 190 对体积干涉检查；21 个刚性机构行程位置；37 个门板退出位置；10 次弹簧垫圈接触距离；闭锁时强制拉门板 0.5 mm 会与锁爪相碰的阻挡测试。输入文件 SHA-256 用于判断报告是否过期。
- 离散采样不是全行程连续碰撞证明。弹簧力、预压、材料、操作力、磨损、强度、疲劳、振动和制造公差均未完成校核；不声明实际可靠复位或给出承载额定值。
- 底板与门板是安装关系演示，最终固定夹具和门板导轨须按真实安装空间设计。
